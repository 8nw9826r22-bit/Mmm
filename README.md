# Streak

A simple calendar and day streak counter. Works offline, installs to the iPhone Home Screen.

## Deploy on GitHub Pages
1. Create a new GitHub repo and upload everything in this folder to the root (index.html must be at the top level).
2. Repo Settings > Pages > Deploy from a branch > `main` / `/ (root)` > Save.
3. Open `https://<your-username>.github.io/<repo-name>/` in **Safari** on your iPhone.
4. Tap Share > Add to Home Screen.

Data is stored on the device (localStorage). Tap a day to mark or unmark it.
